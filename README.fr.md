# Azure AI Foundry Manager

Languages: [English](README.md) | [中文](README.zh-CN.md) | [日本語](README.ja.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Español](README.es.md) | [Português (Brasil)](README.pt-BR.md) | [한국어](README.ko.md)

> Tableau de bord 100% navigateur pour gerer des configurations Azure OpenAI / Azure AI Foundry. Les donnees restent locales (localStorage du navigateur).

## Fonctionnalites

- Gestion multi-comptes / multi-regions
- Repertoire global des modeles (groupes par lignes vides)
- Copie / export des listes de modeles (avec virgules)
- Import / export de configuration (JSON chiffre)
- Historique (jusqu'a 20 versions)
- Mode confidentialite (masquage)
- Langues UI: zh, en, ja, fr, de, es, pt-BR, ko
- Theme: Dark / Light / System
- Command palette: `Ctrl/Cmd + K`

## Demarrage rapide

Prerequis: Node.js 18+ et npm.

```bash
git clone https://github.com/Zeta-ZhaoLi/ai-foundry-manager.git
cd ai-foundry-manager
npm install
npm run dev
```

## Commandes

```bash
npm run test
npm run lint
npm run build
```
