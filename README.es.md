# Azure AI Foundry Manager

Languages: [English](README.md) | [中文](README.zh-CN.md) | [日本語](README.ja.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Español](README.es.md) | [Português (Brasil)](README.pt-BR.md) | [한국어](README.ko.md)

> Panel 100% en el navegador para gestionar configuraciones de Azure OpenAI / Azure AI Foundry. Los datos se guardan localmente en el navegador (localStorage).

## Caracteristicas

- Multi-cuenta / multi-region
- Directorio global de modelos (agrupado por lineas en blanco)
- Copiar / exportar listas de modelos (con comas)
- Importar / exportar configuracion (JSON cifrado)
- Historial (hasta 20 versiones)
- Modo privacidad (enmascarado)
- Idiomas de la UI: zh, en, ja, fr, de, es, pt-BR, ko
- Tema: Dark / Light / System
- Paleta de comandos: `Ctrl/Cmd + K`

## Inicio rapido

Requisitos: Node.js 18+ y npm.

```bash
git clone https://github.com/Zeta-ZhaoLi/ai-foundry-manager.git
cd ai-foundry-manager
npm install
npm run dev
```

## Comandos

```bash
npm run test
npm run lint
npm run build
```
