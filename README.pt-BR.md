# Azure AI Foundry Manager

Languages: [English](README.md) | [中文](README.zh-CN.md) | [日本語](README.ja.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Español](README.es.md) | [Português (Brasil)](README.pt-BR.md) | [한국어](README.ko.md)

> Painel 100% no navegador para gerenciar configuracoes do Azure OpenAI / Azure AI Foundry. Os dados ficam locais no navegador (localStorage).

## Recursos

- Multi-conta / multi-regiao
- Diretorio global de modelos (grupos por linhas em branco)
- Copiar / exportar listas de modelos (com virgulas)
- Importar / exportar configuracao (JSON criptografado)
- Historico (ate 20 versoes)
- Modo privacidade (mascarar dados sensiveis)
- Idiomas da UI: zh, en, ja, fr, de, es, pt-BR, ko
- Tema: Dark / Light / System
- Command palette: `Ctrl/Cmd + K`

## Comecando

Pre-requisitos: Node.js 18+ e npm.

```bash
git clone https://github.com/Zeta-ZhaoLi/ai-foundry-manager.git
cd ai-foundry-manager
npm install
npm run dev
```

## Comandos

```bash
npm run test
npm run lint
npm run build
```
