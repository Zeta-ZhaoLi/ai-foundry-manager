# Azure AI Foundry Manager

Languages: [English](README.md) | [中文](README.zh-CN.md) | [日本語](README.ja.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Español](README.es.md) | [Português (Brasil)](README.pt-BR.md) | [한국어](README.ko.md)

> Browser-basiertes, lokal-first Dashboard zur Verwaltung von Azure OpenAI / Azure AI Foundry Konfigurationen. Alle Daten bleiben im Browser (localStorage).

## Funktionen

- Multi-Account / Multi-Region Verwaltung
- Globales Model-Verzeichnis (Gruppierung per Leerzeilen)
- Copy/Export von Modelllisten (mit Kommas)
- Import/Export der Konfiguration (verschluesseltes JSON)
- Konfigurations-Historie (bis zu 20 Versionen)
- Privacy Mode (Maskierung sensibler Daten)
- UI-Sprachen: zh, en, ja, fr, de, es, pt-BR, ko
- Theme: Dark / Light / System
- Command Palette: `Ctrl/Cmd + K`

## Schnellstart

Voraussetzungen: Node.js 18+ und npm.

```bash
git clone https://github.com/Zeta-ZhaoLi/ai-foundry-manager.git
cd ai-foundry-manager
npm install
npm run dev
```

## Befehle

```bash
npm run test
npm run lint
npm run build
```
