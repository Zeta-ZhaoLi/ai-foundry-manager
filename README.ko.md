# Azure AI Foundry Manager

Languages: [English](README.md) | [中文](README.zh-CN.md) | [日本語](README.ja.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Español](README.es.md) | [Português (Brasil)](README.pt-BR.md) | [한국어](README.ko.md)

> Azure OpenAI / Azure AI Foundry 구성을 브라우저에서 로컬로 관리하는 대시보드입니다. 데이터는 브라우저 localStorage 에만 저장됩니다.

## 주요 기능

- 멀티 계정 / 멀티 리전 관리
- 글로벌 모델 디렉터리(빈 줄로 그룹)
- 모델 목록 복사/내보내기(모델명 뒤에 콤마)
- 설정 가져오기/내보내기(암호화된 JSON)
- 설정 히스토리(최대 20개)
- 프라이버시 모드(민감정보 마스킹)
- UI 언어: zh, en, ja, fr, de, es, pt-BR, ko
- 테마: Dark / Light / System
- 커맨드 팔레트: `Ctrl/Cmd + K`

## 시작하기

요구사항: Node.js 18+ 및 npm.

```bash
git clone https://github.com/Zeta-ZhaoLi/ai-foundry-manager.git
cd ai-foundry-manager
npm install
npm run dev
```

## 명령어

```bash
npm run test
npm run lint
npm run build
```
