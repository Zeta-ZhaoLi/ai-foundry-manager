# Header GitHub Link

## ADDED Requirements

### Requirement: GitHub Link Visible in Header

The application MUST provide a GitHub repository link in the header (top-right) area.

#### Scenario: Header displays GitHub link

**Given** the user opens the application

**When** the header controls are visible

**Then** the UI MUST display a GitHub icon and link in the header

**And** activating the link MUST open the repository in a new tab
